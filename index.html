產品功能

維運所需的一切，集中在一處

從設備收容、監控到設定變更，一個介面完成。

設備收容

單台、批次（CSV）、掃描網段三種方式，快速納管並指定設備角色。

狀態監控

儀表板一眼看到各角色設備的上線、離線與告警數量。

資源與流量

CPU、記憶體、溫度、介面流量與光功率，可指定區間查詢並匯出。

告警與 Syslog

SNMP Trap 與 Syslog 集中管理，可確認、結案並追蹤處理紀錄。

設定備份

定時備份，設備異動前後自動留存，並可批次下載。

設定精靈

步驟引導，一次對多台設備下指令，支援立即、預約與週期執行。

產品功能

維運所需的一切，集中在一處

從設備收容、監控到設定變更，一個介面完成。

設備收容

簡單快速，整個網段一次納管

三種方式快速收容設備，並依角色分類管理。

  • 單台新增、批次新增（CSV 匯入）、掃描網段新增
  • 型號若選錯，同步完成後自動帶入正確型號
  • 可指定設備角色：CO、PE、AR、RR、AN_HUB、CSR
  • 設備清單可篩選、匯出 CSV，並可手動觸發同步
單台新增輸入 IP 與型號

監控

狀態、資源與流量一目了然

儀表板依角色顯示設備上線、離線與告警數量，點擊即可查看明細。

  • Polling 與 Ping 狀態；Ping Fail 告警可自動對消
  • CPU、記憶體、溫度走勢；設備與介面 TX／RX 流量
  • 介面光功率圖，並顯示 warning／alarm 門檻
  • 支援立即與排程重開機

告警與 Syslog

從發現到結案，每一步都有紀錄

整合 SNMP Trap、Chassis Alarm 與 Syslog，集中查看與處理。

  • 匯入或新增 MIB，設定 normal 至 critical 等級
  • 人員確認（Ack）或手動結案（Clear）並填寫備註
  • 儲存篩選條件，每分鐘自動刷新，匯出 CSV
  • Syslog 關鍵字統計，可依等級以 Email 或 Server 轉送

多台設備，一次到位

精靈以步驟引導，完成後加入任務清單，確認後再執行。

  • 上傳設定、模板管理、設備版本更新、RMA 精靈
  • 任務排程：立即、單次預約、週期重複
  • 歷史任務可查看成功／失敗原因並下載執行指令

網路拓撲

整張網路，一張圖看懂

五種拓撲檢視，以顏色區分設備與連線狀態，點擊設備即可查看詳細資訊。

實體拓撲

依「區域 → 環路 → 設備」階層展開，呈現 LLDP 連線。

階層式拓撲

依設備描述、環路編號、網段建立規則群組，最多四層，並可檢視群組內設備告警。

BGP 拓撲

以 Peer State 顯示連線狀態。

Ring 拓撲

依環路編號呈現設備與連線。

PTP／SyncE 拓撲

查看時鐘同步來源與方向。

操作便利

  • 點擊設備查看詳細資訊
  • 直接開啟終端登入設備
  • 拖曳節點並儲存位置
  • 刪除不再存在的連線
階層式拓撲

自訂規則，建立你需要的群組

只看特定型號、環路或網段，一組規則即可呈現。

  • 設備描述條件：HostName、型號或任意字元
  • 環路編號條件：依 Ring ID 建立
  • 網段條件：例如 /24 網段內的設備
  • 群組階層上限四層，第一層不設定規則
